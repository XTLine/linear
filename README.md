# Linear Blog

这是我的个人博客仓库，当前已经清空默认示例内容，后续会逐步补充自己的文章、项目和站点信息。

## 本地开发

```bash
pnpm install
pnpm dev
```

默认开发端口为 `2025`。

## 当前内容位置

- 博客索引：`public/blogs/index.json`
- 博客分类：`public/blogs/categories.json`
- About 内容：`src/app/about/list.json`
- 分享列表：`src/app/share/list.json`
- 项目列表：`src/app/projects/list.json`
- 博客推荐列表：`src/app/bloggers/list.json`
- 站点配置：`src/config/site-content.json`

## 当前状态

- 默认博客文章已删除
- 默认分享、项目、博客推荐内容已清空
- 当前仓库主要作为个人博客的继续定制基础
